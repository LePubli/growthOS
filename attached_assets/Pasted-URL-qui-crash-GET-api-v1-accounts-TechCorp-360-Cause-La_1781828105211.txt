URL qui crash : GET /api/v1/accounts/TechCorp/360
Cause :
La route reçoit "TechCorp" (texte) comme paramètre
Le service getAccount360 passe ce texte directement à upsertMetrics qui attend un UUID
Comparaison text = uuid → crash PostgreSQL
Solution :
Lire artifacts/api-server/src/routes/v1/accounts.ts ligne ~73
Lire artifacts/api-server/src/lib/plugin-account-intelligence/AccountService.ts lignes 190 et 300
Modifier la route pour :
D'abord chercher le compte par nom (WHERE name = $1 OR slug = $1)
Récupérer son UUID
Passer l'UUID à getAccount360
Dans upsertMetrics ligne 190, ajouter un cast explicite si nécessaire : ::uuid ou vérifier le type de la colonne
Gérer le cas "compte non trouvé" → retourner 404 au lieu de 500
