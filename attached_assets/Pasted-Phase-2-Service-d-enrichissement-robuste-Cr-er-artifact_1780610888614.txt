Méthodes du service :
enrichProspect(prospectId) : enrichissement complet avec toutes les sources actives
callAPI(sourceId, prospect, config) : appel API avec retry (3 tentatives) et timeout (10s)
scrapeSource(sourceId, prospect) : scraping avec rate limiting (1 req/seconde)
detectSignals(sourceId, data) : détection de signaux (recrutement, levée de fonds, etc.)
calculateLeadScore(results) : calcul du score 0-100
getFromCache(key) / saveToCache(key, data, ttl) : système de cache
interconnectWithPlugins(prospectId, results, signals) : injection dans Memory, Signals, Accounts
Règles critiques :
Try/catch sur CHAQUE appel de source (si une source échoue, les autres continuent)
Rate limiting strict : jamais plus de 1 req/seconde par source
Timeout : 10 secondes max par appel API
Retry : 3 tentatives avec exponential backoff (2s, 4s, 8s)
Cache : 1 heure pour éviter les doublons
Logs structurés pour chaque action
Toutes les données doivent avoir un champ source et fetchedAt
