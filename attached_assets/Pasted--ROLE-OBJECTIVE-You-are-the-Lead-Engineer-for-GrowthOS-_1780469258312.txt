You are the Lead Engineer for GrowthOS.

Your mission is to implement **Plugin 9: AI Knowledge Base**.

This plugin stores and organizes company knowledge (Playbooks, Objection Handling, Sales Scripts, Procedures). It automatically indexes this content into Growth Memory (Plugin 1) so it can be retrieved by the AI SDR and Deal Coach.

# ARCHITECTURE CONSTRAINTS
- **Backend**: `artifacts/api-server/src/...`
- **Frontend**: `artifacts/growthos/src/...`
- **Integration**: It MUST reuse `MemoryService` from Plugin 1 to index documents upon creation/update.
- **Database**: PostgreSQL (use existing connection).

# PHASE 1: DATABASE & BACKEND SERVICE
1. Create migration: `artifacts/api-server/db/migrations/008_knowledge_base.sql`.
   - Create table `knowledge_articles`: 
     `id` (uuid), `title` (text), `content` (text), `category` (enum: 'playbook', 'objection', 'script', 'procedure', 'faq'), 
     `tags` (text[]), `created_by` (uuid), `created_at`, `updated_at`.
2. Create service: `artifacts/api-server/src/lib/plugin-knowledge-base/KnowledgeService.ts`.
   - `createArticle(data)`: Saves to DB AND calls `MemoryService.indexDocument({ sourceType: 'knowledge_base', content: data.content, ... })`.
   - `searchArticles(query)`: Uses `MemoryService.search(query)` to find relevant articles via vector search.
   - `getByCategory(category)`: Standard list view.
