PHASE 2 : SERVICE D'INSTALLATION DE PLUGINS (BACKEND)
Créez le fichier : artifacts/api-server/src/lib/plugin-uploader/PluginUploaderService.ts
Ce service doit contenir les méthodes suivantes (utilisez fs, path, et adm-zip ou extract-zip pour gérer les fichiers) :
async uploadPlugin(zipBuffer: Buffer, slug: string):
Extrait le ZIP dans uploads/plugins/{slug}/.
Lit et valide le manifest.json à la racine du ZIP avec Zod.
Retourne le chemin et le manifest.
async installPlugin(slug: string):
Copie les fichiers de uploads/plugins/{slug}/ vers src/plugins/installed/{slug}/.
Enregistre dans la DB uploaded_plugins avec state='installed'.
async activatePlugin(slug: string):
Récupère le manifest de la DB.
Appelle le pluginManager.register(manifest) et pluginManager.enable(slug) du core.
Monte dynamiquement les apiRoutes dans le routeur Express principal (utilisez un pattern de routeur dynamique ou chargez le module).
Met à jour la DB : state='active', activated_at=NOW().
async deactivatePlugin(slug: string):
Appelle pluginManager.disablePlugin(slug).
Démonte les routes si possible, ou les ignore via un middleware de vérification d'état.
Met à jour la DB : state='installed'.
async deletePlugin(slug: string): Supprime les fichiers et l'entrée DB.
async listPlugins(): Retourne tous les plugins de la table uploaded_plugins.
